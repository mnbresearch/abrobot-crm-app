# AbroBot CRM — crm.mnbresearch.com

# Until this file existed, a request for /robots.txt was swallowed by the SPA
# catch-all in _redirects and returned the React app: HTTP 200, Content-Type
# text/html, title "AbroBot CRM". So there was effectively no robots.txt, and
# no crawler could discover a sitemap.
#
# A real file at the repo root wins over the catch-all on Cloudflare Pages —
# the same reason /product already serves product.html.
